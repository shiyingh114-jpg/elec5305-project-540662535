The estimated masks do not use clean-source spectra. The oracle power-ratio mask uses both known components and is a reference, not a deployable method or a strict upper bound on SI-SDR. Competing speech is nonstationary, so the simple Wiener noise estimator can fail. Multiplying masks can suppress desired speech as well as interference.

A shared nonnegative mask preserves the mixture interaural ratio before resynthesis; this does not restore clean-target cues in overlapping bins. Cue metrics reanalyse the waveforms, exclude reference silence, and must be interpreted with coverage.

Stage 2 folds binaural estimates to mono and renders them with new measured HRIRs. Its references use the identical fold-down of the clean binaural components, so old HRIR colouration is matched. This is an application demonstration, not clean dry-source recovery.
