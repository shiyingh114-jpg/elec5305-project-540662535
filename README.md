# elec5305-project-540662535
ELEC5305 Audio Signal Processing Project
## Project Title

Perceptually Guided Speech Enhancement and Spatial Re-Mixing for Complex Stereo Audio Scenes

## Project Overview

This project aims to develop a MATLAB-based audio processing system for enhancing target speech in complex stereo audio scenes while preserving and re-designing spatial information.

The proposed system will investigate time-frequency analysis, stereo decomposition, voice activity detection, Wiener-style time-frequency masking, and HRIR/BRIR-based spatial re-mixing.

## Proposed Methods

- Short-Time Fourier Transform (STFT)
- Stereo signal analysis and decomposition
- Voice Activity Detection (VAD)
- Time-frequency masking
- Wiener-style speech enhancement
- HRIR/BRIR-based spatial audio processing
- Objective and perceptual evaluation

## Platform

MATLAB R2025a

## Expected Outcome

The final system will take a complex stereo audio recording as input and generate an enhanced and spatially re-mixed stereo or binaural output with improved speech clarity.

## Project Status

Project proposal and preliminary investigation.
